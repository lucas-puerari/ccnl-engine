# Migration

Pick the guide from the version you have installed (`pip show ccnl-engine`).
There are no aliases: a renamed or moved name fails at import, and each
guide lists what replaces it.

| Installed | Upgrade to | Guide |
|---|---|---|
| 0.5.x | 0.6.0 | [0.5 to 0.6](0.5-to-0.6/index.md), then [earlier changes](0.5-to-0.6/earlier.md) and [inputs and legacy APIs](0.5-to-0.6/legacy.md) |

Releases before 0.5 have no migration guide: their changes are in the
[GitHub releases](https://github.com/lucas-puerari/ccnl-engine/releases).
Upgrade to 0.5.1 first, then follow the guide above.
